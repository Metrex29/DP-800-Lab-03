# DP-800-Lab-03

Laboratorio 3: consultas avanzadas en T-SQL

Autor: Carlos Picon

Este proyecto corresponde al tercer laboratorio del curso DP-800 y está centrado en el uso de T-SQL avanzado para trabajar con datos JSON, funciones de ventana y consultas más complejas sobre la base de datos AdventureWorksLT.

## Objetivo

Aprender a:

- comprobar la conexión con AdventureWorksLT
- generar salida JSON a partir de consultas SQL
- combinar JSON con CTEs y funciones de ventana
- analizar datos JSON mediante OPENJSON
- interpretar resultados útiles para escenarios reales de negocio

## Contenido del laboratorio

- [lab3.md](lab3.md): documentación del ejercicio con la explicación del laboratorio y su estructura
- [images](images): carpeta con las capturas del proceso y resultados visuales

## Tecnologías utilizadas

- SQL Server
- T-SQL
- AdventureWorksLT
- JSON en SQL Server
